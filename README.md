# InfoCite AI

> A production-inspired Hybrid Retrieval-Augmented Generation (Hybrid RAG) system with verified citations.

## Overview

InfoCite AI is an end-to-end Hybrid RAG application that combines:

- Dense Vector Search (Sentence Transformers)
- BM25 Keyword Search
- Hybrid Retrieval
- Cross-Encoder Re-ranking
- LLM-based Answer Generation
- Citation Display
- Citation Verification
- FastAPI Backend
- Streamlit Frontend

This project is being built incrementally following production software engineering practices.
